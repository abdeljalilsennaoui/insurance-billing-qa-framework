# Wiki pages

The published GitHub wiki, kept here under version control. The wiki repository itself has no pull
requests, no review and no CI, so editing a page only there produces a claim nobody checked. These are
the source; the wiki is the copy.

**Published at:** https://github.com/abdeljalilsennaoui/insurance-billing-qa-framework/wiki

## Publishing

```bash
wiki/push-wiki.sh "what changed"
```

The script clones the wiki repository, mirrors this directory into it with `rsync --delete`, copies
`docs/screenshots` in, and pushes. `--delete` matters: it makes this directory the source of truth, so a
renamed or renumbered file does not leave its predecessor behind.

The images are **not** duplicated here. `docs/screenshots` is the only copy, regenerated by
`scripts/capture-screenshots.sh`.

## Checks

`scripts/check-doc-numbers.sh` verifies that every screenshot these pages point at exists in
`docs/screenshots`, and that no screenshot is left unreferenced. CI runs it. A page here that points at
a renumbered image fails the pipeline rather than rendering a broken icon for a reader to find.

> **Note.** GitHub does not create the `…wiki.git` repository until a first page has been saved in the
> browser. On a fresh clone of this project, create any page in the wiki UI once before the first push.
